---
name: app-store-screenshot-design
description: Design production-ready App Store promotional screenshot sets from real app screens with consistent messaging, device framing, localization, and Apple size constraints.
---
Use when preparing App Store marketing screenshots or store-listing visual assets.

1. Start from actual product value and real screens; do not invent features or fake UI states.
2. Define the screenshot narrative: strongest value proposition first, then supporting flows/features.
3. Keep headline copy short, concrete, and consistent across the set.
4. Use device frames only when they improve comprehension; the product UI remains the hero.
5. Preserve safe margins and export at the exact device/display sizes required by the target App Store submission set.
6. Plan localization: allow for longer translated strings and avoid baking text irreversibly into screenshots too early.
7. Keep a consistent composition system across the set while varying enough to maintain visual rhythm.
8. Check small-preview legibility; screenshots are often first seen as thumbnails.
9. Do not imply endorsements, rankings, prices, claims, or capabilities that cannot be substantiated.
10. Verify final exports for dimensions, cropping, color, text clipping, and sequencing.

Treat the set as one visual story, not unrelated posters.
