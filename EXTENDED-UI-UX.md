# Extended UI/UX skills

Kram keeps two UI/UX layers:

1. **Recommended core** — conservative, composable defaults for product, enterprise, admin and backoffice work.
2. **Extended library** — broader creative, research, native-mobile, motion, 3D, branding and ideation skills that are available when the task calls for them.

Extended skills are not lower quality; they are simply more specialized or more opinionated. They must not silently override a project's own frontend standard, design system, domain requirements, accessibility rules, or safety constraints.

## Selection rule

Use the narrowest skill that matches the task. Do not load several art-direction skills at once unless the user explicitly asks for alternatives.

Priority when instructions conflict:

`legal/safety/security -> domain correctness -> project standard -> design system -> usability -> requested creative direction -> visual novelty`

## Extended catalog

### Art direction and style exploration

- `creative-frontend-direction` — distinctive art direction for sites and product surfaces.
- `ui-style-explorer` — compare multiple visual families before committing to one.
- `taste-parameterized-design` — tune variance, motion, and information density explicitly.
- `anti-slop-interface-design` — detect and remove generic AI-template patterns.
- `design-memory` — persist approved interface decisions across long-running projects.
- `ux-innovative-design` — deliberately explore unconventional interaction patterns.
- `ux-controlled-design` — design within strict enterprise/regulatory constraints.

### Research, strategy, evaluation

- `design-research-and-strategy` — personas, journeys, discovery, UX strategy and design ops.
- `design-sprint` — structured understand/sketch/decide/prototype/test workflow.
- `hooked-retention-ux` — analyze retention loops without using manipulative dark patterns.
- `design-rating-scorecard` — score a UI across hierarchy, spacing, color, typography, accessibility and coherence.

### Platform engineering

- `react-performance-ui` — React rendering and performance review.
- `react-composition-patterns` — scalable React component API/composition patterns.
- `react-native-ui-performance` — performant React Native lists, images, navigation and animation.
- `ios-hig-design` — native iOS/SwiftUI design using Apple HIG principles.

### Design-to-code and brand systems

- `figma-to-code-handoff` — translate supplied Figma specs into production UI while preserving the project's architecture.
- `theme-factory` — construct or compare complete semantic theme families.
- `brand-guidelines` — turn brand rules into enforceable interface decisions.
- `visual-canvas-design` — plan standalone visual artifacts rather than application UI.
- `skill-authoring` — create and review reusable Kram skills.

### Motion, spatial and marketing assets

- `motion-microinteractions` — purposeful motion and interaction polish.
- `scroll-driven-experience` — scroll-linked storytelling with progressive enhancement and QA.
- `immersive-scroll-world` — cinematic scene-based scroll experiences with explicit cost/performance gates.
- `image-to-threejs` — reconstruct a visual reference as procedural Three.js code.
- `app-store-screenshot-design` — production App Store promotional screenshot sets.
