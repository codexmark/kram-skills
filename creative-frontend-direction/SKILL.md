---
name: creative-frontend-direction
description: Choose a distinctive visual direction for a frontend when the user wants expressive, non-generic art direction rather than conservative product defaults.
---
Use for landing pages, portfolios, campaign surfaces, experimental product areas, or when the user explicitly asks for a strong visual identity.

1. Read existing brand/design constraints first; do not erase an established product language without permission.
2. Declare one art direction before coding: typography mood, palette logic, composition grammar, texture/depth, and motion character.
3. Avoid statistical AI defaults: generic purple gradients, identical icon cards, centered-everything layouts, arbitrary glassmorphism, and interchangeable SaaS sections.
4. Make macro-composition carry the concept. Typography, scale, whitespace, asymmetry, imagery, and rhythm should work before decorative effects.
5. Keep accessibility and responsive behavior first-class; expressive does not mean illegible.
6. Use motion only when it supports hierarchy, spatial understanding, or brand character.
7. Prefer a small number of deliberate signature moves over many weak effects.
8. Verify the result in the renderer at desktop and mobile sizes.

Do not use this skill as the default for dense enterprise/backoffice screens unless the user explicitly requests a more expressive direction.
