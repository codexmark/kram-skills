---
name: ux-innovative-design
description: Explore unconventional interaction and layout ideas when the user explicitly wants novelty, differentiation, or a new interaction model.
---
Use for concept exploration, new consumer products, creative tools, experimental interfaces, and redesigns where conventional patterns are part of the problem.

1. Keep the user goal and domain constraints explicit; novelty is not the goal by itself.
2. Generate multiple interaction concepts before choosing one.
3. For each concept identify: what conventional pattern it replaces, why the replacement may be better, discoverability risk, accessibility risk, implementation cost, and fallback behavior.
4. Prototype risky interactions before spreading them across the product.
5. Preserve familiar anchors for navigation, escape, undo, help, and destructive actions.
6. Never use dark patterns, forced engagement, obscured cancellation, or manipulative urgency.
7. Validate with representative tasks rather than aesthetic preference alone.
8. If an experimental pattern fails usability or accessibility review, revert to a proven pattern.

Innovation is successful only when it improves the experience, not merely when it looks different.
